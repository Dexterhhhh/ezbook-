# 衡财 iOS

原生 SwiftUI 客户端，以本项目中的 Go HTTP API
作为唯一业务与财务数据源。

## 环境

- Xcode 26.6
- Swift 6，严格并发检查
- iOS 18+
- iPhone 与 iPad

## 本地运行

1. 按主项目文档启动数据库、迁移和 Go API。
2. 在 Xcode 中打开 `invest&pay.xcodeproj`。
3. 选择 iOS 模拟器并运行。
4. App 的“设置”中确认 API 地址为 `http://127.0.0.1:8080`。
5. 输入本地服务配置中的 API 凭据，登录并绑定设备。

真机不能使用 `127.0.0.1` 访问 Mac。请改为 HTTPS 或私人 VPN 地址；开发时使用
局域网地址会触发系统本地网络权限请求。不要把当前无设备认证的 `:8080` 服务暴露
到公网。

## 已实现

- 概览、记账、账单、趋势、投资、设置六个原生 Tab。
- Swift Concurrency + `URLSession` + `Codable` 网络层。
- API Key + 密码登录、Bearer 设备会话、Keychain 安全存储及本设备撤销。
- 统一成功包裹、结构化错误、请求 ID、409/月结冲突提示。
- `Int64` 最小货币单位和 `Decimal` 展示/输入。
- 临时消费录入与现金人工确认。
- 招商银行信用卡 PDF 预览、校验和确认导入。
- 自然月账单审核、绝对值金额排序、推送及月结。
- 按币种分别展示和汇总投资持仓。
- ATS 最小本地网络例外与本地网络用途说明。
- 隐私清单声明不跟踪、不收集开发者数据，并为 App 内部 UserDefaults 配置申明
  `CA92.1` required-reason API 用途。

## 服务端限制

当前已完成设备认证与撤销，但尚未开放增量同步 API。正式远程使用前仍须配置 HTTPS
或私人 VPN；不要通过明文 HTTP 在不受信任网络上传输登录凭据或财务数据。
